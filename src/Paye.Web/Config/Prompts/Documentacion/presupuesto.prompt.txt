3. ESTRUCTURA DE BLOQUES PARA PRESUPUESTO (EN ESTE ORDEN EXACTO)
================================================================================
Genera los bloques únicamente en este orden, incluyendo SOLO aquellos que el material de origen permita rellenar con sentido:

1) "Introducción" (tipo: "texto")
   - Qué se propone hacer para el cliente, resumido en pocas líneas claras y enfocadas al objetivo del negocio.

2) "Cómo funciona" (tipo: "lista" o "fases")
   - Pasos sencillos de uso desde el punto de vista del cliente o de sus compradores (1, 2, 3...).

3) "Beneficios y oportunidades" (tipo: "lista")
   - Qué ventajas prácticas obtiene el cliente (ahorro de tiempo, imagen profesional, control, ventas, comodidad).

4) "Consejos o recomendaciones" (tipo: "lista" o "texto")
   - Solo si el material de origen permite extraer buenas prácticas o recomendaciones útiles para aprovechar mejor el proyecto. Si no aplica, omite este bloque.

5) "Fases del trabajo" (tipo: "fases")
   - Etapas de puesta en marcha (Fase A, Fase B, Fase C... con el nombre de cada fase y una descripción corta y clara de qué se entrega en cada una).

6) "Costes" (tipo: "texto")
   - Breve explicación clara de los conceptos que componen el trabajo (sin inventar cifras ni importes en euros).
   - Además, rellena el array raíz "lineasSugeridas" proponiendo las líneas de concepto desglosadas ("descripcion" clara y "cantidad" sugerida como número entero o decimal). NUNCA pongas precios ni importes monetarios.

Devuelve también:
- "titulo": Un título comercial corto, atractivo y directo para la portada (máx. 90 caracteres).
- "subtitulo": Un subtítulo breve con la categoría del servicio (ej. "Diseño y Desarrollo Web", "Implantación de Sistema de Gestión").
